# 🌐 Web Mini Projects

A collection of **small web development projects** built using **HTML, CSS, and JavaScript**.  
This repository is created to practice core web concepts, improve problem-solving skills, and build a strong frontend foundation.

---

## 🚀 Projects Included

### 1️⃣ Random Quote Generator
- Generate random motivational quotes
- Clean and responsive UI
- Built using pure JavaScript logic

**Tech Used:** HTML, CSS, JavaScript

---

### 2️⃣ Quiz App
- Multiple-choice questions
- Score calculation
- Interactive UI with instant feedback

**Tech Used:** HTML, CSS, JavaScript

---

### 3️⃣ Notes App
- Add and delete notes
- Persistent storage using `localStorage`
- Simple and user-friendly design

**Tech Used:** HTML, CSS, JavaScript

---

### 4️⃣ Guess The Number Game
- Guess a number between 1 and 100
- Hints for high/low guesses
- Attempt counter and restart option

**Tech Used:** HTML, CSS, JavaScript
